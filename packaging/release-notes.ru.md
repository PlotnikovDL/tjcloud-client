Клиент для 64-разрядной Windows. Среда .NET входит в комплект.

- Для установки скачайте файл `*-setup.exe`. Установщик предложит папку `C:\Program Files\TJCloudClient`. Для установки нужны права администратора. Сам клиент работает с правами обычного пользователя.
- Для запуска без установки распакуйте ZIP-архив и откройте `TjCloudClient.exe`.

При переходе с пользовательской установки 1.0.1 отключите её автозапуск, закройте клиент через трей и удалите старую программу в параметрах Windows. Затем запустите новый установщик. Профиль, ключ и очередь сохраняются.

Контрольные суммы файлов приведены в `SHA256SUMS.txt`. Установщик и список обновлений `appcast.xml` подписаны ключом Ed25519. Происхождение файлов можно проверить по подтверждениям сборки GitHub. У EXE нет подписи издателя Windows (Authenticode).

Публикация в каталоге WinGet выполняется отдельно.

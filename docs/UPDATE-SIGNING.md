# Ключ подписи обновлений

Автообновления используют отдельную пару Ed25519. Открытый ключ включается в приложение. Закрытый ключ нужен только для выпуска подписанного пакета и appcast.

## Где разрешено использовать ключ

- Закрытый ключ хранится в секрете `SPARKLE_PRIVATE_KEY` окружения GitHub `release`.
- Окружение допускает только теги `v*` и требует подтверждения владельца репозитория. Обычные ветки и PR не должны получать этот секрет.
- Открытый ключ находится в `TjClient.Wpf/Updates/UpdatePublicKey.txt`. Публиковать его безопасно и необходимо для проверки обновлений.
- Секрет нельзя передавать через аргументы команды, печатать в журнал или добавлять в Git. Генератор получает его через окружение только своего процесса.
- Перед публикацией нужно независимо проверить подпись установщика и подпись appcast открытым ключом из той же версии клиента. Успешного exit code генератора недостаточно.

## Резервная копия

Локальная резервная копия закрытого ключа защищена DPAPI CurrentUser и ограничением доступа к каталогу. Она находится вне репозитория. Такой файл привязан к Windows-профилю: одной копии файла может быть недостаточно после переустановки ОС или переноса на другой компьютер.

До массового распространения нужно обеспечить отдельную защищённую и проверяемую процедуру восстановления ключа. Не отправляйте ключ в Issues, чат или обычную почту. Наличие секрета в GitHub не заменяет резервную копию: GitHub не предоставляет его значение обратно через API.

Не создавайте новую пару поверх существующей. Установленные клиенты доверяют старому открытому ключу. При потере закрытого ключа обновления с новым ключом не станут доверенными автоматически; потребуется план перехода или ручная установка.

## Что подпись не подтверждает

Ed25519 подтверждает, что данные подписаны обладателем закрытого ключа и не изменились после подписания. Это не проверка безопасности кода, не гарантия свежести версии и не Authenticode-подпись издателя Windows. Проверки версии, допустимого источника, кода, сборки и безопасного перезапуска остаются обязательными.

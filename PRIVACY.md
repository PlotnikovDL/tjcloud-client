# Конфиденциальность в TJCloud Client

TJCloud Client читает завершённые файлы технологического журнала 1С из выбранной папки и доставляет их получателю, адрес которого указан в настройках. Содержимое журналов может включать имена пользователей, тексты запросов и другие рабочие сведения. Клиент передаёт содержимое без обезличивания. Выбирайте для отправки только данные, которые вы вправе передать этому получателю.

## Что получает сервер

При проверке подключения клиент отправляет по HTTPS ключ источника выбранному серверу. При доставке сервер получает относительный путь файла, размер, контрольную сумму и содержимое журнала. Ключ используется для авторизации запросов. Перед первой отправкой пользователь проверяет получателя, подтверждает завершённость файлов и разрешает передачу. При смене адреса клиент запрашивает ключ и подтверждение заново.

Чтобы остановить отправку, нажмите «Пауза». Чтобы отозвать разрешение, снимите флажок согласия на передачу получателю. Это прекращает последующую доставку. За хранение уже полученных журналов и их удаление отвечает оператор выбранного сервера. По вопросам доступа или удаления переданных данных обращайтесь к нему.

## Что остаётся на компьютере

Профиль, ключ и очередь хранятся в `%LOCALAPPDATA%\TJCloudClient`. Профиль с ключом защищён Windows DPAPI для текущей учётной записи. В SQLite-очереди сохраняются относительные пути, размеры, даты файлов, контрольные суммы, идентификаторы передач и состояние доставки. Исходные журналы остаются в выбранной папке.

Чтобы удалить локальный профиль, ключ и историю очереди, полностью завершите клиент через меню значка в трее и удалите каталог `%LOCALAPPDATA%\TJCloudClient`. При следующем запуске потребуется настроить подключение и выбрать начальный режим наблюдения заново.

## Проверка обновлений

Для клиента, установленного через Setup, пользователь отдельно разрешает обращения к GitHub за обновлениями. GitHub и его служба доставки файлов получают обычные сетевые запросы, включая IP-адрес подключения. Ключ источника и содержимое журналов передаются только получателю журналов. Разрешение на автообновления можно отозвать в настройках клиента. Portable-копия обновляется вручную.

С вопросом о поведении Windows-клиента можно обратиться к [сопровождающему проекта](https://github.com/PlotnikovDL/tjcloud-client/issues). Для публичного обращения достаточно версии приложения и описания ситуации. Рабочие журналы, ключ и файлы профиля содержат конфиденциальные сведения.
